Yea-fs — Games

Minimal static launcher — click a game to open it. Serve `/public` with a static server (see README-games.md).

  • 2048
    Classic sliding-tile puzzle (MIT-like minimal implementation)
  • Tetris
    Canvas Tetris — keyboard controls (← → ↓ / Space)
  • Snake
    Classic snake on canvas — arrow keys
  • DOOM (placeholder)
    WASM engine + FreeDoom WAD required. See `instruction.json` / README-games.md.
Run locally: python3 -m http.server --directory public 8000 and open http://localhost:8000/games/
