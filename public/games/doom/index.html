🎮 DOOM

⚠️ Docker Setup Required

This DOOM integration uses restful-doom, which runs as a Docker container that exposes an HTTP API.

To play DOOM, you need to:

  1. Download FreeDoom WAD files from freedoom.github.io
  2. Place freedoom1.wad or freedoom2.wad in public/games/doom/wads/
  3. Run the Docker container using one of these methods:

🐳 Docker Setup Instructions

Option 1: Docker Compose (Easiest)

docker-compose up

This will build and start the restful-doom server on port 6666.

Option 2: Manual Docker Commands

# Build the image
docker build -f public/games/doom/Dockerfile.build -t restful-doom-build .

# Run the container
docker run --rm -v "$PWD/public/games/doom/wads":/wads -p 6666:6666 restful-doom-build \
  bash -c "WAD=$$(ls /wads/freedoom*.wad | head -1) && /opt/restful-doom/src/restful-doom -iwad $$WAD -apiport 6666 -window"

Option 3: Using the Helper Script

cd public/games/doom
./run_restful_doom.sh

🎯 Game Interface

Note: This is a server-side DOOM instance with an HTTP API. For a full browser-based experience, you would need to implement a JavaScript client that sends commands to the API and displays the game state.
